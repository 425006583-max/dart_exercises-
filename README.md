## Scenario

This program demonstrates a simple student store purchase using Dart variables, data types, arithmetic operators, comparison operators, and console input/output.

## Data Types Used

The program uses the four required Dart data types:

- **String** – stores the student's name.
- **int** – stores the quantity of items.
- **double** – stores the item price, total, discount, and final total.
- **bool** – stores the student's status and discount eligibility.

## Operators Used

The program demonstrates:

- `*` – calculates the total price.
- `-` – calculates the final price after the discount.
- `>=` – checks if the purchase is eligible for a discount.
